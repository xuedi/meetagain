# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub's **Report a vulnerability** button on the Security tab, or by email to
xuedi@meetagain.org. Include what you found, how to reproduce it, and the version or commit you tested.

You will get an answer as soon as possible. Once a fix is released, the report can be made public, with credit
to you if you want it.

## Supported versions

Only the latest release receives security fixes.
