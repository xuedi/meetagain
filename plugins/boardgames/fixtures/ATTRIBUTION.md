# Board game fixture photos: sources and licences

Demo photographs for the board game fixtures, downloaded from Wikimedia Commons and centre-cropped to 1000x1000 for the
square box-image ladder. Every file below is reused under the licence named in its row, which requires the attribution
given here. Do not add a file to this directory without adding its row.

Commons carries photographs *of games in play and of their components*, not publisher box art - box art is copyrighted
and is not sourced here. Four titles had no freely licensed photograph on Commons at all and were replaced in
`Kernel::catalog()` by classics that do: Backgammon, Crokinole, Halma and The Werewolves of Millers Hollow.
